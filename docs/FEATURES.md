# Streetwise: Feature Documentation

This page sorts everything in Streetwise into three groups: what we had to build for the MVP, what we built beyond it with the time we had, and what comes in future iterations.

**How we defined the MVP:** the core planning-and-saving loop. A user can create a trip plan, see a budget, set up a Wise Jar to save for it, and track their plans. Everything on screen is simulated sample data (see the README for what's real and what's simulated).

| Feature                                           | What it does                                                                                                                                                     | Status    | Notes                                                                                                              |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------ |
| **1. MVP: what we had to build**                  |                                                                                                                                                                  |           |                                                                                                                    |
| Create-a-plan wizard (3 steps)                    | Guides the user from choosing a budget approach, to trip details, to setting up a Wise Jar                                                                       | Built     | Replaced a chatbot after Wise feedback: planning is a short guided form                                            |
| Two budget approaches                             | "Wise recommended budget" estimates the trip for the user. "Create your own budget" takes a daily target and works out the total trip cost                       | Built     | Estimates come from fixed formulas and lookup tables, not live prices                                              |
| Trip details                                      | Destination, trip length, travellers and price range (standard, boost, luxury), with optional flight and accommodation costs                                     | Built     | Leave costs blank to get an estimate                                                                               |
| Budget breakdown                                  | Shows the trip total and a split across categories (flights, accommodation, itinerary extras, food, transport, activities and buffer)                            | Built     | Calculated by plain code in the page                                                                               |
| Wise Jar setup                                    | Sets a savings goal by weekly amount (slider shows the funded-by date) or by deadline (shows the weekly and monthly amount needed)                               | Built     | Jar is simulated, not connected to a real Wise account                                                             |
| My plans and trip detail                          | Lists saved plans with Jar progress, a budget breakdown, and a "+ Add £20 to Jar" button that updates the Jar live                                               | Built     | Plans reset on refresh                                                                                             |
| Wise-style interface                              | Mobile layout with Wise-style colours and a bottom navigation. The Travel tab holds Streetwise, and Home is a placeholder for Wise's own dashboard               | Built     | Unofficial, not affiliated with Wise                                                                               |
| Seeded demo data                                  | Three example plans (Lisbon, Rome, Paris) so the demo works without setup                                                                                        | Built     | Illustrative numbers, not tuned to be consistent with each other                                                   |
| Hackathon deliverables                            | Public repo, README with real-versus-simulated table and AI usage disclosure, prototype history (iterations kept in `prototype/`)                                | Built     |                                                                                                                    |
| **2. Built beyond the MVP, with the time we had** |                                                                                                                                                                  |           |                                                                                                                    |
| Currency toggle                                   | Views and saves the Jar goal in the destination currency (for example EUR), converted live when toggled                                                          | Built     | Uses the app's own fixed rate table, not a live feed                                                               |
| Itinerary builder with price estimates            | Add attractions and restaurants to an itinerary and get an estimated price for each                                                                              | Built     | Lookup table only recognises a small set of keywords                                                               |
| Named landmark pricing                            | Recognised landmarks (for example the Eiffel Tower) are priced at their real ticket cost, not a generic guess                                                    | Built     | Small hard-coded set                                                                                               |
| Price Confidence screen (scan prototype)          | Shows how a scanned price could be checked against the budget                                                                                                    | Prototype | Sample items only, no real camera. Reachable from trip detail and shown live as a forward-looking part of the idea |
| Live pace and warnings screen                     | Shows how spending pace and shortfall warnings could look during a trip                                                                                          | Prototype | Sample data, not wired into the main planning flow                                                                 |
| Feedback-driven simplification                    | Cut an advertising placeholder and a round-up toggle, renamed "travel style" to "price range", and reworked the daily-spend input so it can't be read as a total | Done      | Based on Wise employee feedback                                                                                    |
| Iteration history                                 | Earlier prototype versions kept so the evolution of the idea is visible                                                                                          | Done      | See `prototype/`                                                                                                   |
| **3. | Real camera scan                                  | Photograph a menu or price tag and see the translation, the price in the user's currency, and its effect on the budget                                           | Not built | Originally planned for the MVP, cut for time and team skills                                                       |
| Correction step                                   | If a scan misreads a price, the user fixes it and the app shows exactly what changed                                                                             | Not built | Originally planned, cut for time                                                                                   |
| Payment screen with currency-choice warning       | Simulated terminal that warns when a card machine offers to charge in the wrong currency                                                                         | Not built | Originally planned, cut for time                                                                                   |

| Saved plans                                       | Keep plans between sessions (local storage first, then a real backend)                                                                                           | Not built |                                                                                                                    |
